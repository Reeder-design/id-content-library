Tiny user guide

Library Manager, in plain English

You should not need to remember Git, folders, file paths, or how the site is built. Just tell the Manager what the thing is.

  1. 1
    Add your project.

    Choose one file or one complete folder. The Manager handles the library copies behind the scenes.

  2. 2
    Check the suggestions.

    Title, format, tools, and preview behavior are guessed from the files. Change anything that looks wrong.

  3. 3
    Save locally and preview.

    Your changes stay on your computer. Preview the item or the whole library and keep editing until it feels right.

  4. 4
    Review & Publish.

    The Manager validates the library, summarizes the batch, and only sends it to GitHub when you explicitly publish. Once it reaches main, the public Lab deployment updates automatically.

Rule of thumb: if a field feels technical, leave the smart suggestion alone unless you know you want something different.
Public-safe reminder: anything you publish belongs in the public Learning Content Lab. Keep confidential or unsanitized work out of this repository.
