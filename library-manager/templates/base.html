Tiny user guide

Library Manager, in plain English

You should not need to remember Git, folders, file paths, or how the site is built. Just tell the Manager what the thing is.

  1. 1
    Add your project.

    Choose one file or one complete folder. The Manager handles the library copies behind the scenes.

  2. 2
    Check the suggestions.

    Title, format, tools, and preview behavior are guessed from the files. Change anything that looks wrong.

  3. 3
    Add the human stuff.

    Pick what kind of resource it is, write a short description, and add useful tags.

  4. 4
    Review before saving.

    Nothing is published to GitHub from this screen yet. Publishing controls arrive in Phase 7.

Rule of thumb: if a field feels technical, leave the smart suggestion alone unless you know you want something different.
